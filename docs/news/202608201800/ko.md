## Managed Apps

원클릭 호스팅 앱: URL로 바로 실행되는 서비스를 제공하며, 그 아래 모든 처리는 우리가 담당합니다. [lnvps.net/apps](https://lnvps.net/apps)에서 카탈로그를 확인하세요.

- 한 번의 양식으로 배포, 지역을 선택하고 이름을 입력하면 완료
- 직접 도메인을 연결
- 언제든 이름 변경, 재구성 또는 리사이징 가능. 이미 결제한 시간만큼 크레딧이 적용됩니다
- CPU, 메모리, 스토리지 사용량을 플랜 대비 표시
- 배포 페이지에서 시작, 중지, 삭제

## 결제

- **온체인 비트코인**: 라이트닝 및 카드와 함께
- **저장된 카드와 지갑**: 이름 지정 및 기본값 선택 가능
- **자동 갱신**: 신규 VM은 기본적으로 켜져 있으며, 원할 때 언제든 꺼둘 수 있습니다
- **취소된 VM에 대한 자동 라이트닝 환불**
- 헤더에 **VAT 토글**이 있으며, 모든 청구서에 EU 세금 처리가 정확히 적용됩니다
- **더 명확해진 결제 화면**: 중단된 결제는 결제 내역에서 다시 이어서 진행할 수 있습니다

## 나의 VM

- **다른 OS로 재설치**: 새로 디자인된 선택기에서
- **새 운영체제 8가지**: AlmaLinux, Rocky Linux, Alpine, NixOS, OpenBSD, NetBSD, Gentoo, Void Linux
- **SSH 키 페이지**: 각 키가 어떤 머신에 사용되고 있는지 표시
- **SSH 호스트 키 지문**: 최초 연결 시 서버를 확인할 수 있습니다
- 커스텀 빌드에서 **IPv4와 IPv6 주소를 선택**
- **스토리지 중심으로 재설계된 커스텀 VPS 주문**
- 갱신되지 않은 VM의 **실제 삭제일** 표시, 호스트가 폐기되는 경우 사전 알림
- 신규 VM에서 **더 빠른 디스크**: 기존 VM은 다음 중지/시작 시 적용
- Google 및 패스키 계정에 대한 **동작하는 웹 콘솔**

## 지원

- LNVPS 지원 에이전트와 **라이브 채팅**: 계정을 확인하고 머신을 시작, 중지 또는 다시 시작할 수 있습니다. 연장, 환불, 삭제는 여전히 이메일로 처리됩니다.
- 기존 메시지 탭을 대체하는 **알림**
